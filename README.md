# 🔐 CyberSafe – Cybersecurity Awareness Quiz App

An interactive web quiz app to test and improve cybersecurity knowledge, built with HTML, CSS, and JavaScript.

## Features
- 14 questions across 4 topics: CIA Triad, Phishing, Network Security, Password Safety
- Filter quiz by specific topic or play all
- Instant feedback with detailed explanations per question
- Progress bar and live score tracker
- Topic-wise breakdown in results screen
- Randomized question order every attempt
- Responsive dark-themed UI

## Tech Stack
- HTML5
- CSS3 (CSS Variables, Grid, animations)
- Vanilla JavaScript (DOM manipulation, shuffle algorithm)

## How to Run
1. Clone this repository
2. Open `index.html` in any browser — works offline!

## Deploy on GitHub Pages
1. Go to repo **Settings → Pages**
2. Set source to `main` branch → `/ (root)`
3. Live at: `https://yourusername.github.io/cybersafe`

| 🎣 Phishing | Social engineering, spear phishing |
